# 🏋️‍♂️ React Workout: The Fitness Park

Welcome to the **React Workout Circuit**! This repository is designed to sharpen your React and React Native muscles through high-intensity, focused "Stations."

## 🏁 The Circuit Rules
1. **Choose a Station:** Navigate to any folder in `/stations`.
2. **Read the Brief:** Open the `README.md` in that station for your goals and constraints.
3. **Start the Clock:** Each exercise is designed to be completed in **10-15 minutes**.
4. **Pass the Tests:** Run `npm test` inside the station. Your goal is to turn all those red lights green.
5. **No Cheating:** Follow the "Constraints" section strictly (e.g., "No `useEffect`").

## 🚦 Getting Started
1. Install dependencies: `npm install`
2. Run the test suite: `npm test`
3. Start the dev server: `npm run dev`

## 🏗️ The Stations
1. **Station 1: The Filter Sprint** - Master derived state and controlled inputs.
2. **Station 2: Async Interval** - Handle data fetching, loading, and error states.
