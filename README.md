# 🏋️‍♂️ React Workout: The Fitness Park

Welcome to the **React Workout Circuit**! This repository is designed to sharpen your React and React Native muscles through high-intensity, focused "Stations."

## 🏁 The Circuit Rules
1. **Choose a Station:** Navigate to any folder in `/stations`.
2. **Read the Brief:** Open the `README.md` in that station for your goals and constraints.
3. **Run a Lap:** Do **not** commit to `main`. Create a new branch for each "lap" around the circuit (e.g., `git checkout -b lap-1`). This keeps the base stations clean so you can share them or retry later.
4. **Push Your Limits:** Each station has multiple Levels (e.g., `Level1.tsx`, `Level2.tsx`). Attempt to push yourself to a harder level on each subsequent lap!
5. **Start the Clock:** Each exercise is designed to be completed in **10-15 minutes**.
6. **Pass the Tests:** Run `pnpm test` inside the station. Your goal is to turn all those red lights green.

## 🚦 Getting Started
1. Install dependencies: `pnpm install`
2. Run the test suite: `pnpm test`
3. Start the dev servers (Web): `pnpm run dev`

## 🏗️ The Stations
1. **01-filter-sprint**: Master derived state and controlled inputs.
2. **02-async-interval**: Handle data fetching, loading, error states, and unmounting.
3. **03-form-validation**: Master controlled inputs and real-time form validation.
4. **04-reducer-pattern**: Understand and implement `useReducer` for complex state.
5. **05-context-theme**: Pass state deeply without prop drilling using Context.
6. **06-custom-hook**: Abstract complex logic into reusable React Hooks (`useLocalStorage`).
7. **07-rn-basics**: React Native & Expo fundamentals (Web preview available).
