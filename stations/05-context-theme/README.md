# ⏱️ Station 5: Context Theme Switcher

## 🎯 The Goal
Pass state deeply through the component tree without prop drilling using React Context.

## 📋 Levels
- **Level 1:** Static `ThemeContext` consumption in a nested child component.
- **Level 2:** Create a `ThemeProvider` and custom `useTheme` hook for state management.
- **Level 3:** Implement a dynamic theme toggle within a deeply nested child.

## ⏱️ Estimated Time
10-15 Minutes
