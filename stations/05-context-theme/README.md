# ⏱️ Station 5: Context Theme Switcher

## 🎯 The Goal
Pass state deeply through the component tree without prop drilling using React Context.

## 📋 Levels
- **Level 1:** Create a Context and a Provider.
- **Level 2:** Consume the context in a child component to apply styles.
- **Level 3:** Add a toggle switch to dynamically change the theme context.
