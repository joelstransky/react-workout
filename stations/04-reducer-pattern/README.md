# ⏱️ Station 4: The Reducer Pattern

## 🎯 The Goal
Understand and implement `useReducer` for complex state management.

## 📋 Levels
- **Level 1:** Basic counter using `useReducer` with increment, decrement, and reset.
- **Level 2:** Simple shopping cart using `useReducer` to add/remove strings.
- **Level 3:** Advanced cart handling objects, quantity updates, and total price calculation.

10-15 Minutes
