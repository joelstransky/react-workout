# ⏱️ Station 6: Custom Hooks (useLocalStorage)

## 🎯 The Goal
Abstract complex logic into reusable custom React Hooks.

## 📋 Levels
- **Level 1:** Read and write a value to `localStorage` inside a standard component.
- **Level 2:** Extract the logic into a generic `useLocalStorage` custom hook.
- **Level 3:** Add JSON parsing and handling to support arrays/objects in your hook.
