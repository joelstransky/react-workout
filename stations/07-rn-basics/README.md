# 📱 Station 7: React Native Basics

## 🎯 The Goal
Learn the fundamentals of building mobile applications with React Native.

## 📋 Levels
- **Level 1:** Layout fundamentals using `View`, `Text`, and `StyleSheet` (centering titles).
- **Level 2:** Using `FlatList` to render and style lists efficiently.
- **Level 3:** Adding interaction with `TouchableOpacity` and feedback via `Alert.alert`.

## ⏱️ Estimated Time
15-20 Minutes
